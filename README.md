## 🚀 Огляд та можливості

* **Щосекундна телеметрія**: Безперервний збір завантаження процесора (загальне та покадрово по ядрах), оперативної пам'яті (Used/Free/Max), файлу підкачки (Swap), дискового та мережевого I/O (байт/с).
* **Моніторинг дискретного GPU NVIDIA**: Пряма інтеграція з драйвером через `nvidia-ml-py` (`pynvml`): відсоток утилізації, виділена відеопам'ять VRAM та температура GPU.
* **Оптимізоване сканування процесів**: Сканування раз на 5 секунд в окремому ізольованому потоці за допомогою `psutil.Process.oneshot()` з кешуванням імен процесів та швидким розрахунком RAM без зайвих викликів Windows API.
* **Двигун тривог (Alerts Engine)**:
  * Правила спрацьовування: CPU > 90% понад 30 с, RAM > 85% понад 10 с, вільне місце на диску < 5%, температура GPU > 85 °C понад 30 с.
  * Фіксація топ-3 процесів-винуватців (culprits snapshot) у момент перевищення.
  * Захист від спаму: одна активна тривога на одне правило до повернення в норму (`resolved_at`).
* **База даних SQLite у WAL-режимі**: Паралельний доступ без блокувань (`WAL`, `PRAGMA synchronous=NORMAL`, `timeout=5.0`).
* **Диференційована ротація даних (Retention)**:
  * Сирі 1-секундні записи: **2 години**
  * Похвилинні агреговані метрики: **30 днів**
  * Звичайні знімки процесів: **24 години**
  * Тривоги та їх знімки процесів: **30 днів**
  * Погодинне використання програм: **30 днів**
* **Аналітика та прогнозування**:
  * Розрахунок інтегрального індексу стану системи (Health Index 0–100%).
  * Час перебування телеметрії у «червоній зоні».
  * Лінійний прогноз заповнення дискових розділів (`days_to_full`).
* **Звіти Excel (.xlsx, openpyxl)**:
  * 6 структурованих аркушів: «Характеристики», «Зведення», «Метрики», «Програми», «Сповіщення», «Поради ШІ».
  * Вбудована стилізована лінійна діаграма телеметрії (фірмові кольори, пунктир для пікових навантажень, легенда знизу, підписи осей).
* **ШІ-порадник (Gemini 3.5 Flash Lite)**:
  * Автоматичні поради з оптимізації системи на основі компактного зрізу телеметрії.
  * Інтерактивний чат-порадник (ліміт 500 символів, до 6 останніх реплік контексту).
  * 5-хвилинне кешування автопорад.
  * Автоматичний офлайн-фолбек на локальну евристику при відсутності мережі, лімітах 429 чи відсутності ключа.
  * Опція анонімізації назв процесів (`AI_SEND_PROCESS_NAMES=false`).
* **Десктопна інтеграція**:
  * Нативне вікно на рушії Edge Chromium (WebView2 / `pywebview`) 1280×800.
  * Системний трей Windows (`pystray`): згортання при закритті вікна хрестиком, відновлення по подвійному кліку, швидкий експорт звіту у `Документи\SystemMonitor\`, пауза/відновлення збору.
  * Захист від повторного запуску (Single Instance): активація наявного вікна при повторному відкритті.
  * Ротаційне логування у `logs/system-monitor.log` поруч із `.exe`.

## 🏛 Архітектура системи

```
┌─────────────────────────────────────────────────────────────┐
│                 System Monitor Architecture                 │
└─────────────────────────────────────────────────────────────┘

 [Фонові потоки збору]
   ├── SystemMetricsThread (1 с) ──> psutil
   ├── ProcessCollectorThread (5 с) > oneshot(), кеш PID
   └── GpuCollectorThread (2 с) ────> pynvml (NVIDIA Driver)
                   │
                   ▼
       [SQLite Database: monitor.db]
         ├── Режим WAL + busy_timeout=5000
         ├── DataAggregatorThread (60 с, ротація)
         └── AlertManager (фіксація винуватців)
                   │
                   ▼
         [Flask REST API Server]
         ├── /api/status, /api/metrics/live
         ├── /api/analytics, /api/export/excel
         └── /api/ai/advise, /api/ai/chat, /api/ai/status
                   │
                   ▼
       [Десктопний шар інтерфейсу]
         ├── pywebview (WebView2 / Edge Chromium)
         ├── Pystray (Системний трей Windows біля годинника)
         └── Дашборд: HTML5 + Vanilla CSS + Vanilla JS + Chart.js
                   │
                   ▼
     [ШІ-порадник: Gemini REST / Fallback]
         ├── urllib.request HTTPS (x-goog-api-key)
         └── fallback_advisor.py (автономні правила)
```

## 🔧 Встановлення та налаштування

### 1. Системні вимоги
* **ОС**: Windows 10 / 11 (64-bit)
* **Python**: 3.10 або новіший
* **Відеокарта** *(опціонально)*: NVIDIA з встановленими драйверами (для моніторингу GPU)

### 2. Створення віртуального оточення та встановлення залежностей
```powershell
# Створення віртуального середовища
python -m venv .venv

# Активація
.venv\Scripts\activate

# Встановлення необхідних бібліотек
pip install -r requirements.txt
```

### 3. Налаштування файлу конфігурації `.env`
Скопіюйте приклад файлу налаштувань:
```powershell
copy .env.example .env
```
Відкрийте `.env` у текстовому редакторі та налаштуйте параметри:
```ini
# Хост та порт локального веб-сервера
HOST=127.0.0.1
PORT=5050

# Моніторинг дискретної відеокарти NVIDIA (true/false)
GPU_MONITORING=true

# Google Gemini API Key для роботи ШІ-порадника
# Отримати безкоштовний ключ: https://aistudio.google.com/
GEMINI_API_KEY=your_gemini_api_key_here

# Модель Gemini (за замовчуванням gemini-3.5-flash-lite)
GEMINI_MODEL=gemini-3.5-flash-lite

# Приватність: передавати реальні назви процесів моделі (true)
# або анонімізувати їх як "процес 1, процес 2..." (false)
AI_SEND_PROCESS_NAMES=true
```

> **Важливо**: Якщо `GEMINI_API_KEY` не вказано або відсутній доступ до інтернету, застосунок автоматично переходить у **автономний режим** (всі функції оптимізації виконуються локальним модулем евристик `fallback_advisor`).

## 🖥 Запуск із вихідного коду

### Режим десктопного вікна (рекомендований):
```powershell
python run.py
```
* Відкривається нативне вікно WebView2 (1280×800) з фірмовою іконкою.
* У системному треї (біля годинника) з'являється іконка застосунку.
* Закриття вікна хрестиком ховає його в трей, не перериваючи збір метрик.
* Для повного виходу скористайтеся пунктом **«Вихід»** у контекстному меню трею.

### Режим звичайного веб-браузера:
```powershell
python run.py --browser
```
Застосунок запускається як фоновий сервер, доступний за адресою: [http://127.0.0.1:5050](http://127.0.0.1:5050).

## 📦 Збірка портативного .exe

Для створення повністю автономного виконуваного файлу `SystemMonitor.exe` (не потребує встановленого Python на цільовому ПК):

```powershell
python build.py
```

### Особливості збірки:
1. **Скрипт `build.py`**:
   * Автоматично генерує векторно-вивірені іконки `icon.png` та `icon.ico` через Pillow (`tools/make_icon.py`).
   * Запускає PyInstaller з файлом конфігурації `monitor.spec`.
   * Автоматично видаляє тимчасовий каталог `build/` після завершення збірки.
2. **Параметри `monitor.spec`**:
   * `onefile=True`: єдиний монолітний файл `dist/SystemMonitor.exe`.
   * `console=False`: чисто десктопний запуск (без вікна чорної командної стрічки).
   * **Безпека**: база даних `monitor.db` та конфігураційний файл `.env` **НЕ вшиваються** у бінарник.
3. **Робота скомпільованого `.exe`**:
   * При першому запуску файл `.env` та база `monitor.db` шукаються/створюються **поруч із `.exe`**.
   * Логи програми пишуться у підкаталог `logs/system-monitor.log` поруч із `.exe` з ротацією (макс. 5 МБ, 3 файли архіву).
   * Статичні файли дашборду розпаковуються у тимчасовий каталог `sys._MEIPASS` і обслуговуються прозоро.

## 🔒 Безпека та приватність

1. **Повна локальність**:
   Усі зібрані метрики, знімки процесів, журнал тривог та історія чату зберігаються **виключно локально** у файлі бази даних `monitor.db` на вашому комп'ютері.
2. **Захист API-ключа**:
   * Ключ Gemini API зберігається лише у файлі `.env`.
   * Передається виключно в HTTP-заголовку `x-goog-api-key` по захищеному протоколу TLS/HTTPS безпосередньо на сервери Google.
   * Ніколи не потрапляє в URL-параметри, логи застосунку, відповіді API або вікно інтерфейсу.
3. **Приватність назв процесів**:
   При встановленні прапорця `AI_SEND_PROCESS_NAMES=false` у файлі `.env`, усі назви процесів перед відправкою до моделі ШІ знеособлюються у вигляд «процес 1, процес 2…».
4. **Автономність**:
   System Monitor повноцінно працює офлайн без доступу до Інтернету — локальний евристичний порадник забезпечує аналіз продуктивності навіть за відсутності мережі.
